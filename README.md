# VulnTrack AI

VulnTrack AI is a cybersecurity vulnerability tracking platform that helps users search and understand known exploited vulnerabilities using data from the CISA Known Exploited Vulnerabilities (KEV) catalogue.

## Problem

Finding relevant vulnerabilities in a large catalogue can be time-consuming. VulnTrack AI aims to make vulnerability information easier to search, filter and understand.

## Planned Features

- Retrieve vulnerability data from CISA.
- Search vulnerabilities by CVE ID.
- Filter records by vendor, product and date.
- Store vulnerability records in SQLite.
- Provide REST API endpoints using FastAPI.
- Add AI-powered search and answers with source citations.
- Test and document the application.

## Technology Stack

- Python
- JSON
- SQLite and SQL
- FastAPI
- Git and GitHub
- pytest
- LLM APIs for future AI features

## Project Status

Currently in development. Features will be implemented incrementally.

## Data Source

[CISA Known Exploited Vulnerabilities Catalog](https://www.cisa.gov/known-exploited-vulnerabilities-catalog)

## Goal

Build a reliable, testable backend application while learning practical software engineering and AI application development.
